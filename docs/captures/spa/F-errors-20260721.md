## 使用约定

1. **先分面再处置**：CF HTML ≠ 协议 4xx ≠ token 401 ≠ 业务 quota/moderation。混判会导致「乱换号」或「误删号」。
2. **同出口对照**：仅 curl_cffi 失败、Camoufox 成功 → 记 **栈差异**，不记字段缺口（见 §7）。
3. **本批未采到样例**的类别仍占位，标注「待补证据」，避免调度脚本臆造匹配规则。

## 1. CF HTML 403（边缘拦截）

| 项 | 内容 |
|----|------|
| **现象** | `GET chatgpt.com/` 或 `sentinel/.../prepare`（及偶发 poll）返回 **HTTP 403**，body 为 HTML challenge / 拦截页，而非 JSON。仓内常归类为 `cloudflare_or_edge_html_block`。 |
| **典型 body / 特征** | HTML（含 cloudflare / cf-ray / challenge 类标记）；`ensure_ok` 会压成短文案：`cloudflare_or_edge_html_block: … Usually intermittent proxy/CF edge block — retry or switch egress; not necessarily an invalid token.` |
| **本批观测点** | panda 直连：`chat_requirements_prepare` **连续 5 次** CF HTML 403，首页亦 403，未进入 conversation prepare/SSE（bench3 §5）。Webshare 轮：首页可 soft-fail 403，但 finalize/SSE/下载仍可通（bench3 §6）。 |
| **建议处置** | **换出口 / 换号（sticky 好）**；IMAGE/文本路径按 `17` 做 CF failover，**勿当 token 失效删号**。协议改 Header **不能**根除。机房 IP 若必须用 → 考虑浏览器栈（§7），非「再猜字段」。 |
| **证据** | `docs/captures/spa/bench3-20260721.md` §5–§7；`docs/17-cf403-and-egress.md`「现象与识别」「协议绕过裁决」 |

## 2. TLS / 传输失败

| 项 | 内容 |
|----|------|
| **现象** | 请求未形成有效上游业务响应：连接/握手失败或中途断开；重试后可能成功。 |
| **典型 body / 特征** | 异常字符串含：`OPENSSL invalid library`、`curl: (35)`、`SSLEOF`、`Recv failure`、`Connection`（bench3 / `12`）。**无**稳定 JSON error code。 |
| **本批观测点** | 本地 Clash + curl_cffi：首几次 TLS 失败后重试成功，生图闭环 OK（bench3 §4.5）。`12`：Clash 上 curl_cffi 间歇 OPENSSL/SSLEOF，标为传输问题，非协议字段。 |
| **建议处置** | **同出口短退避重试**（脚本侧已有 attempt 循环）；持续失败再换节点/代理进程。不要因此改 conversation body。 |
| **证据** | `docs/captures/spa/bench3-20260721.md` §4.5、§7.2；`docs/12-protocol-gap-vs-web.md`「仍存差距」§2 |

## 3. 协议 422（请求体不合规）

| 项 | 内容 |
|----|------|
| **现象** | 已过 CF/sentinel，业务 API（如 `/f/conversation/prepare`）返回 **HTTP 422**。 |
| **典型 body / 特征** | 本批记录：prepare `partial_query` **缺 `author.role`** → 422（已修 fallback body）。样例结果文件名（gitignore）：`data/runlogs/spa_repro/bench3/result_panda_webshare_1784614811.json`。 |
| **建议处置** | **修 builder / 对齐 SPA 字段**（非换号）。对照 `field-diff` + HAR；补单测。勿与 CF403 混用换号逻辑。 |
| **证据** | `docs/captures/spa/bench3-20260721.md` §6.5；字段对齐见 `docs/12-protocol-gap-vs-web.md`、`docs/captures/spa/field-diff-20260721.md` |

## 4. 401 / token 失效

| 项 | 内容 |
|----|------|
| **现象（仓内区分口径）** | Access token 无效/撤销 → 鉴权失败；**不得**与 CF HTML 403 等同。`17` 明确：`cloudflare_or_edge_html_block` / `is_cf_edge_chat_error` ≠ token 失效。 |
| **典型 body / 特征** | **本批 SPA 三轮 / panda SOCKS 对照未采到 401 样例**（账号固定且 token 有效）。生产侧常见文案线索（非本批 SPA 抓包）：`status=401` / `token invalidated` / `invalid_access_token`（见运维日志与 refresh 路径，**此处不伪造 SPA body**）。 |
| **建议处置** | **刷新 token / 换号（删无效 token）**；确认非 CF HTML 后再走 invalid 路径。 |
| **证据** | 区分原则：`docs/17-cf403-and-egress.md`「现象与识别」；本批「未命中」：`bench3-20260721.md`、`panda-socks-camoufox-20260721.md`（失败面为 CF/栈，非 401） |
| **待补** | 故意过期 token 在 Clash 上打 `/f/conversation` 的 status+body 样例 → 写入本文件下一版 |

## 5. Quota（额度耗尽 / 限流类）

| 项 | 内容 |
|----|------|
| **现象** | 上游或调度层拒绝继续生图/对话：号池侧 `quota=0` / `no available image quota`，或上游 rate limit 类响应。 |
| **典型 body / 特征** | **本批 SPA 对照未采到上游 quota/429 业务 JSON**（三轮成败由出口/CF/栈决定；成功轮仍有额度）。调度文案 `no available image quota` 属**本仓号池**，不是 SPA HAR 错误体。 |
| **建议处置** | 调度：**换有额度号**；区分「账面 quota」与 schedulable。上游 429：退避 + 换号，勿当协议字段错误。 |
| **证据** | 本批未命中上游样例：`bench3` / `panda-socks` / `12` / `17` 均未给出 SPA quota body。处置原则间接来自 `17`（撞边缘换号）与生产调度经验——**上游 body 待补**。 |
| **待补** | 限流号真实 `/f/conversation` 或 tasks 错误 JSON 各 1 条 |

## 6. Moderation（内容政策）

| 项 | 内容 |
|----|------|
| **现象** | 请求已进对话，SSE/轮询出现内容拦截（生图或文本被拒）。 |
| **典型 body / 特征** | **本批 SPA 生图 prompt 成功出图，未触发 moderation。** 仓内消费约定（非本批抓包）：SSE `type=moderation` 且 `moderation_response.blocked=true`；或后续 tasks/conversation 文案含 policy/blocked 等（代码路径存在，**不能当作本批已验证的上游原文**）。 |
| **建议处置** | **不换出口重试同一违规 prompt**；记业务失败 / 换安全 prompt；与 CF/TLS 分离。 |
| **证据** | 本批未命中：`bench3-20260721.md`（成功轮 `has_image_gen=true`）。分类需求见 `docs/19` §F。 |
| **待补** | 故意触发拦截的 SSE 片段 + tasks 详情各 1 条 |

## 7. 栈差异（同 IP：Camoufox vs curl_cffi）

| 项 | 内容 |
|----|------|
| **现象** | **同一出口 IP** 上，真浏览器（Camoufox/Firefox TLS）可通过 home + sentinel prepare/finalize + conversation prepare；`curl_cffi` impersonate 在同 IP 上卡在 CF HTML 403。进一步：暖 cookie 后 curl_cffi 发 SSE 仍可能 403。 |
| **典型 body / 特征** | Camoufox：`GET /` → 200（~513KB HTML）；`req_prepare`/`finalize`/`conversation_prepare` → 200 + `conduit_token`。curl_cffi 直连同 IP：prepare 连续 CF HTML 403。暖 cookie + curl_cffi SSE：`{"phase":"sse_done","status":403,"mode":"curl_cffi_socks","has_image_gen":false}`。 |
| **出口** | `43.156.233.219`（panda 公网；与容器直连一致）。 |
| **建议处置** | **换栈**（Camoufox / 暖机交接 PoC）或 **换 sticky 好出口**（Webshare 已证全链路 OK）。禁止把该失败记成「SPA 字段缺口」。长 SSE：勿用 Playwright APIRequest 整包缓冲（曾 200 流后 30s 超时）。 |
| **证据** | `docs/captures/spa/panda-socks-camoufox-20260721.md` 全文；与 bench3 直连 FAIL 对照见该文「与三轮对照的关系」；裁决细化：`docs/17-cf403-and-egress.md`（不推翻「勿依赖协议绕过」） |

## 8. 快速分流表（调度用）

| 信号 | 优先归类 | 动作 |
|------|----------|------|
| 403 + HTML / `cloudflare_or_edge_html_block` | CF 边缘 | 换出口/换号；不删 token |
| `OPENSSL` / curl 35 / `SSLEOF` | TLS/传输 | 重试 → 换节点 |
| 422 + JSON（如缺 `author.role`） | 协议体 | 修代码 |
| 401 / token invalidated（待补样例） | Token | 刷新/剔号 |
| quota=0 / no available image quota | 调度额度 | 换有额度号 |
| SSE moderation blocked（待补样例） | 内容政策 | 换 prompt，不换 CF 策略 |
| 同 IP：Camoufox 200 / curl_cffi 403 | 栈差异 | 换栈或换出口 |
