## 7. 对照观察

1. **同协议、同账号**：Clash 与 Webshare 均可完整生图+下载；panda 公网直连不行。
2. **耗时**：Webshare 56.9 s < 本地 Clash 78.4 s；差距主要在 requirements（1.1 s vs 7.1 s）及本地 Clash TLS 抖动。
3. **流量**：主体为 PNG 下行（~2.3–2.5 MB）；控制面仅数 KB。
4. **CF**：首页/部分 poll 可 403，但 sticky Webshare 上 sentinel+SSE+下载仍可通；直连 IP + curl_cffi 在 sentinel 即死。**但**同 IP 经本机 SOCKS + Camoufox 可过 prepare（见附录文档）。
5. **生产启示**：继续按 `docs/17` — sticky 好出口 + 撞 CF 换号；勿指望协议绕过 CF；机房 IP 若强行使用需浏览器级 TLS。
